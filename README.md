# MSH2LM - أدوات بث TikTok المجانية

أدوات بث TikTok المجانية من مشعل — مصممة لصناع المحتوى العرب.

## المميزات

- **آخر متابع** - عرض آخر متابع لك مباشرة
- **Top 3 تكبيس** - عرض أكبر 3 متصدرين في التكبيس
- **آخر أحبني** - عرض آخر شخص أحب البث
- **اختصار مدمج** - اختصار روابط مدمج في الأداة

## التشغيل

### الطريقة السريعة

1. افتح مجلد المشروع في Terminal
2. شغّل الأمر التالي:

```bash
npx serve .
```

3. افتح المتصفح على `http://localhost:3000`

### الطريقة البديلة

يمكنك استخدام Python لتشغيل الموقع:

```bash
# Python 3
python -m http.server 3000

# Python 2
python -m SimpleHTTPServer 3000
```

## الاستخدام مع OBS

1. شغّل الموقع على السيرفر المحلي
2. في OBS، أضف مصدر "Browser" (متصفح)
3. اضبط الرابط على `http://localhost:3000`
4. اضبط الحجم والصورة حسب حاجتك

## الملفات

- `index.html` - الصفحة الرئيسية
- `assets/` - الملفات الثابتة (JS, CSS, خطوط)
- `msh2lm-logo.png` - شعار الموقع
- `manifest.json` - ملف PWA للتطبيقات
